# Zonderq UI — mapa rozwoju

1. v0.1 — starter APK: launcher, szuflada aplikacji, demonstracyjny control center, demonstracyjny lockscreen, testy CI.
2. v0.2 — działający launcher: pełna lista aplikacji, widgety, foldery, własne ikony, zachowane ustawienia.
3. v0.3 — design system: motywy, przejścia, animacje, narzędzia screenshot-testing.
4. v0.4 — moduł zasobów/RRO dla dostępnych publicznie zasobów Androida (tylko zgodne zasoby overlay).
5. v1.0 — SystemUI z prawdziwą obsługą powiadomień, Quick Settings, Keyguard: dopiero po przygotowaniu gałęzi źródeł systemu i ARM64 GSI.

NIE instalować prototypu APK jako /system/priv-app, NIE nadpisywać systemowego SystemUI, NIE zmieniać vbmeta/super.
